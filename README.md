# Medical Support Unit (MSU) Portal

The **Medical Support Unit (MSU) Portal** is a role-based web application built for the medical team at **Faith Tabernacle** to manage patient care and daily clinic operations efficiently. Designed to replace manual workflows, it helps doctors, nurses, and lab staff deliver organized, high-quality healthcare services.

---

## 📌 Overview

The MSU Portal centralizes core clinical activities—such as patient registration, treatment records, queue management, and lab result tracking—into a single secure platform. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, it combines modern web performance with a clean and user-friendly interface.

---

## ✨ Features

- **Patient Management**: Register new patients, update profiles, and track visit history.
- **Queue Management**: Organize and monitor patient flow in real time to reduce wait times.
- **Role-Based Access**: Ensure doctors, nurses, and lab staff see only what they need based on their roles.
- **Medical Records**: Record diagnoses, treatments, prescriptions, and lab results.
- **File Uploads**: Attach medical reports, test results, and other documents to patient profiles.
- **Protected Layout**: Secure authentication and protected routes to keep patient data private.

---

## 🛠 Technology Stack

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand

---

Clone the repository and install dependencies:
